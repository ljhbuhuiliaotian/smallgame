# 扫雷游戏技术架构

## 1. 架构设计
```
┌─────────────────────────────────────┐
│            HTML5 单页应用           │
├─────────────────────────────────────┤
│  游戏状态管理 │ 渲染引擎 │ 计时器    │
├─────────────────────────────────────┤
│        鼠标事件 │ 触摸事件处理       │
└─────────────────────────────────────┘
```

## 2. 技术选型
- **前端**: 纯HTML5 + CSS3 + Vanilla JavaScript
- **动画**: CSS3 Transitions
- **计时器**: setInterval
- **事件**: 鼠标点击 + 右键 + 触摸长按

## 3. 游戏逻辑
| 功能 | 描述 |
|-----|------|
| 网格系统 | 二维数组存储每个单元格状态 |
| 布雷算法 | 随机布雷，首击保护(第一次点击不会踩雷) |
| 数字计算 | 统计周围8格的地雷数量 |
| 空白展开 | 递归揭開相邻空白区域 |
| 胜利判定 | 所有非地雷格子被揭開 |
| 失败判定 | 点击到地雷 |

## 4. 难度配置
| 难度 | 网格 | 地雷数 |
|-----|------|-------|
| 初级 | 9x9 | 10 |
| 中级 | 16x16 | 40 |
| 高级 | 30x16 | 99 |
