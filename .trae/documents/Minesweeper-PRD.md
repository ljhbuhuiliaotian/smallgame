# 扫雷游戏 PRD

## 1. 产品概述
经典扫雷游戏的网页版本，玩家在网格中揭开方块，避开地雷，找出所有安全区域。游戏具有标记地雷功能、计时器和胜利/失败判定。

## 2. 核心功能

### 2.1 功能模块
1. **游戏主页**: 雷区网格、计时器、地雷计数、重新开始按钮

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 游戏主页 | 雷区网格 | 初级9x9/中级16x16/高级30x16网格，支持左键揭開、右键标记 |
| 游戏主页 | 信息面板 | 显示剩余地雷数量、计时器、重置按钮 |
| 游戏主页 | 难度选择 | 初级/中级/高级三种难度级别 |
| 游戏主页 | 游戏结束弹窗 | 游戏结束时显示结果和再来一局选项 |

## 3. 核心流程
```
选择难度 → 初始化雷区 → 玩家点击 → 判断(地雷/数字/空白) → 递归展开空白区域 → 检查游戏状态(胜利/失败) → 循环
```

## 4. 用户界面设计

### 4.1 设计风格
- **主题**: 复古Windows风格 + 现代扁平化改良
- **主色调**: 浅灰色背景 (#c0c0c0 经典配色)
- **方块样式**: 凸起3D效果，未揭开/已揭开/标记有区分
- **字体**: Segoe UI / Quicksand
- **布局**: 居中单页设计，响应式适配

### 4.2 视觉细节
- 方块具有立体感，按下时有凹陷效果
- 数字使用不同颜色 (1蓝色, 2绿色, 3红色等)
- 地雷使用黑色圆形+十字图标
- 标记使用红色小旗图标

### 4.3 响应式设计
- 桌面端: 固定尺寸网格，精确点击
- 移动端: 较大触控区域，支持长按标记
